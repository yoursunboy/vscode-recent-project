# 需求

## 背景与目标

VS Code 自带的「最近打开」在「欢迎页 / 文件菜单」里，路径层级深、不便查看和批量操作。本扩展把最近项目放到**侧边栏常驻入口**，并补充备注、置顶、删除等轻量管理能力，方便在多个项目之间快速切换。

## 核心需求

1. **读取历史**：从 VS Code 自身的持久化存储中读取最近打开的项目文件夹（而非自己另存一份，避免重复维护）。
2. **常驻展示**：在活动栏提供「最近项目」视图，侧边栏列表展示项目文件夹名、备注、最后编辑时间、完整路径。
3. **一键打开**：点击列表项在**当前窗口**打开；按住 `Ctrl`（macOS `Cmd`）点击在**新窗口**打开。
4. **轻量管理**：支持置顶、添加/清除备注、从列表移除。
5. **搜索**：按名称 / 路径 / 备注关键字过滤。
6. **无效项目隐藏**：文件夹已不存在的项目不显示（`missing` 标记）。

## 功能需求明细

| 编号 | 需求 | 交互 |
|---|---|---|
| F1 | 读取各 VS Code 变体的最近项目 | 自动，激活时 + 工作区变化时 |
| F2 | 侧边栏展示最近项目列表 | 活动栏图标进入 |
| F3 | 当前窗口打开项目 | 单击列表项 |
| F4 | 新窗口打开项目 | `Ctrl`/`Cmd` + 单击 |
| F5 | 置顶 / 取消置顶 | 点击星标 |
| F6 | 编辑 / 清除备注 | 点击编辑按钮，弹输入框 |
| F7 | 从列表移除（墓碑，防复活） | 点击删除按钮 |
| F8 | 按名称/路径/备注搜索 | 顶栏搜索框 |
| F9 | 手动刷新列表 | 视图标题栏刷新按钮 / `recentProject.refresh` |
| F10 | 展示最后编辑时间 | 扩展扫描文件夹内最新 mtime 计算 |
| F11 | 中文 / 英文文案 | 跟随 VS Code 显示语言 |

## 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 扫描文件夹 mtime 时限制 ≤ 2000 个条目，避免卡死 |
| 本地化 | 清单与 Webview 文案均支持 `zh` / `en` |
| 兼容性 | 覆盖 Windows / macOS / Linux 的存储路径；兼容 Code / Insiders / VSCodium / Cursor |
| 健壮性 | 单个数据源读取失败不阻断其他来源；wasm 加载失败给出警告而非崩溃 |
| 安全 | 只处理本地 `file` scheme；忽略远程工作区 |

## 范围边界（明确不做）

- **不**支持远程 / 非本地工作区（`vscode-remote://` 等）。
- **不**支持单文件历史（只保留文件夹与 `.code-workspace`）。
- **不**做多窗口实时同步（依赖 VS Code 自身历史刷新）。
- 列表上限 **100 条**（`MAX_PROJECTS`）。
